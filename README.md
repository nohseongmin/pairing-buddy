# 페어링 버디 — 프로토타입

취향을 스와이프하면 오늘의 술·안주 페어링을 추천해 주는 앱의 화면 프로토타입입니다.
빌드 도구 없는 정적 페이지 한 장(`index.html`)이라 파일만 열어도 그대로 돌아갑니다.

## 화면

| 탭 | 내용 |
| --- | --- |
| 취향 | 술 카드를 좌우로 밀어 취향을 수집 (드래그 · 버튼 · 키보드 ←/→) |
| 추천 | 분석 결과로 술+안주 페어링과 근처 구매처 표시 |
| 발견 | 소규모 양조장·전통주 소개 + 사진 출처 |

## 실행

로컬에서 보려면 이 폴더에서 정적 서버를 띄웁니다.

```bash
python -m http.server 8099
```

`index.html`을 더블클릭해도 열리지만, `file://` 로 열면 브라우저에 따라 이미지 경로가 막힐 수 있어 서버 실행을 권합니다.

## 배포

`main` 에 푸시하면 GitHub Actions(`.github/workflows/deploy.yml`)가 저장소 루트를 그대로 GitHub Pages 로 올립니다.
별도 빌드 단계는 없습니다.

## 사진 교체

`images/` 안의 파일을 **같은 이름**으로 덮어쓰면 자동 반영됩니다. 파일이 없거나 로드에 실패하면 이모지가 대신 보입니다.

| 파일 | 쓰이는 곳 | 권장 비율 |
| --- | --- | --- |
| `sool-makgeolli.jpg` | 취향 카드 · 막걸리 | 1:1 |
| `sool-sake.jpg` | 취향 카드 · 사케 | 1:1 |
| `sool-ipa.jpg` | 취향 카드 · IPA | 1:1 |
| `sool-highball.jpg` | 취향 카드 · 하이볼 | 1:1 |
| `sool-soju.jpg` | 취향 카드 · 증류식 소주 | 1:1 |
| `sool-wine.jpg` | 취향 카드 · 레드와인 | 1:1 |
| `pair-makgeolli.jpg` | 추천 화면 · 왼쪽(술) | 4:3 |
| `anju-jeon.jpg` | 추천 화면 · 오른쪽(안주) | 4:3 |

술·안주 목록과 문구는 `index.html` 아래쪽 `SOOL` / `DISCOVER` 배열만 고치면 됩니다.
사진을 바꾸면 `CREDITS.md` 와 `index.html` 의 `CREDITS` 배열도 함께 갱신하세요.
